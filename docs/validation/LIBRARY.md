# 首页与 Library 分离验收

2026-09-27（America/New_York）。用户确认：Library 使用滚动自动加载，每批 10 条；首页 Recent shares 保留 5 条。

- `/`：链接提交、最新 5 条有效分享和 View all shares；无筛选及翻页入口。
- `/library`：全部历史分享，按 `(created_at, id)` 倒序，首次服务端渲染 10 条。关键词、成员、日期筛选只在此页提供；未选日期时查询全部历史。
- 接近底部时按签名游标取下一批 10 条，保留手动按钮支持键盘操作和浏览器降级。每次仅一个请求，网络失败保留当前结果并可重试，游标过期可重新加载。
- 筛选条件变化时列表重新挂载、清空旧页并取消未完成请求；按分享 ID 去重。处理状态更新合并到已加载结果，不重置累计页数。
- Home、Library、详情和不可用页面的导航已对应新路由；Library 不重复展示提交表单。
- 原 REST/MCP 默认最近 7 天、20 条的契约未更改，网页显式提供历史起点和条数。游标保持初始上界及过滤条件，刷新页面才纳入后来新增的分享。
