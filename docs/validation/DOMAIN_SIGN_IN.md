# 公司账号自动加入

2026-09-27 用户修正：任何 `@authright.com` 用户都可登录，这是唯一准入限制，不需要先手动添加成员。

## 当前行为

- Google 完成身份认证后，服务端校验返回的邮箱已验证且精确属于 `authright.com`，大小写不敏感；拒绝其他域、子域、伪装后缀和未验证邮箱。
- 移除认证库的 `hd` 选项：锁定的 Better Auth 1.7.6 会据此强制校验 Workspace 声明，不仅是账号选择提示。现在只使用已认证的已验证邮箱决定公司资格。
- 首次创建会话时自动建立普通成员，按用户行锁串行化同一身份的并发首次会话。预设管理员仍通过 bootstrap 绑定；普通首次登录不自动提权。
- 已有用户和历史分享保持同一 `user.id`。旧 `status=disabled` 不再阻止访问，登录时改为 active；历史撤销的 Agent 连接保持撤销。
- 显示名优先使用 Google 姓名（去除首尾空白），缺失、空字符串或纯空白时使用邮箱 `@` 前的完整部分，例如 `tao.xu@authright.com` → `tao.xu`。新建账号及 Google 资料映射使用同一规则；历史空姓名在分享、详情、成员查询、管理员页和账户页读取时同样回退，不改变身份或分享归属。
- 管理页只列出已绑定用户及当前姓名/邮箱，保留角色调整与最后一个已绑定公司管理员保护。手动添加、禁用按钮、成员 POST 接口及 `member:disable` 脚本均移除；PATCH 只接受 role。
- 当前管理员自己的成员行标注 `You`，不显示角色切换按钮；其他成员仍可由管理员调整角色，服务端继续保护最后管理员。
- 网页和 MCP 每次业务访问使用相同的已验证公司邮箱检查。MCP 继续校验 Token、scope、个人连接授权；用户仍能撤销自己的连接。
- 成员查询的 active 由公司邮箱资格计算，旧 disabled 值不会把公司成员显示为不可访问。

## 数据兼容

无需数据库迁移。旧 `allowed_email` 保留为初始身份/bootstrap 邮箱，旧 `status` 保留兼容字段，不作为允许名单或准入条件。不会删除历史成员、分享或连接记录，也不会恢复已经撤销的 Token。

公司资格使用 Google 登录时保存的已验证身份及当前数据库资料；未接入 Google Directory 实时停用通知，因此不宣称 Google 管理后台停用账号会立即使已签发的本地会话失效。

## 网页认证错误

Google 登录默认错误出口和显式 error callback 均指向 `/auth-error`。页面区分链接过期、登录未完成和服务暂时不可用，提供重新登录、返回 Sharing 与 Agent 重连说明，不直接显示供应商 message 或 error_description。

认证回调和 OAuth authorize 的浏览器页面导航若直接返回 4xx/5xx，由路由转成本站错误页，同时保留认证库清理状态 Cookie 的响应。fetch/SDK、Token 交换和 MCP 仍保留原状态码与结构化 JSON，正常授权重定向不改写。

## 验证范围

- 单元：精确域名、大小写、伪装后缀、子域及未验证邮箱。
- 集成：真实认证库的用户/会话钩子，无预录记录的首次会话自动建档；并发幂等；旧管理员角色、旧禁用记录、身份变更与历史分享；网页/MCP 非公司身份拒绝；个人连接撤权回归；最后管理员并发保护。
- 浏览器：通过会话钩子自动建立测试成员，桌面/手机网页流程，管理页不存在添加/禁用按钮，旧 POST 返回 405，status PATCH 返回 400。
- 本轮没有代替同事执行真实 Google 登录；自动化会话仍限定在隔离测试数据库，不引入生产测试入口。

运行命令：`pnpm check`、`pnpm test:integration`、`pnpm build`、`pnpm test:e2e`。

结果：36 项单元测试、14 项集成测试、6 项桌面/手机 Chromium 测试全部通过，静态检查、Web/Worker 构建和客户端秘密扫描通过。浏览器服务端仍偶发此前记录的 `The destination stream closed early`，未导致用例失败，尚未确认根因。未执行新的真实 Google 登录验收。

后续网页交互修正回归：43 项单元测试、14 项集成测试、8 项桌面/手机 Chromium 测试及构建通过。新增覆盖自身管理员按钮隐藏、失效回调的恢复页面、授权失败页面、Token 端点继续返回 JSON，以及页面不展示传入的原始错误详情。授权端点本身允许重定向，JSON 回归使用 Token 端点验证，不把 OAuth 正常重定向误判为错误。

姓名回退修正：44 项单元与 15 项集成测试通过。覆盖 Google 姓名优先、缺失/空白姓名使用邮箱本地部分、新用户创建钩子，以及历史空姓名在分享列表/详情、成员查询、管理列表和账户资料中的一致展示；分享 DTO 不因内部读取邮箱而新增邮箱字段。
